# CareerVerify AI 🤖

CareerVerify AI is an AI-powered resume and job description verification system that helps students and job seekers understand how well their resume matches a particular job role.

## 🚀 What Does CareerVerify AI Do?

CareerVerify AI allows users to:

- 📄 Upload their resume
- 💼 Enter a Job Description (JD)
- 🤖 Analyze the resume using AI
- 🎯 Identify the suitable job role
- 📊 Calculate the resume match score
- ✅ Find matching skills
- ❌ Identify missing skills
- 🔍 Verify skills using evidence from the resume
- 📚 Recommend courses for missing skills
- 💬 Chat with an AI assistant about the resume and job
- 🎤 Get interview topics based on the job role

## ⭐ Key Feature

### Evidence-Based Skill Verification

Instead of simply saying that a candidate has a skill, CareerVerify AI checks whether the resume provides evidence for that skill.

For example:

**Skill:** React

**Status:** ✅ VERIFIED

**Evidence:** React is mentioned in the candidate's project experience.

This helps users understand which skills are actually supported by their resume.
